# Как получить APK F.R.I.D.A.Y. OS Mobile

В этой среде Android SDK/Gradle не установлены, поэтому готовый APK здесь не собран.
В проект добавлен GitHub Actions workflow, который соберёт APK на GitHub.

## Шаги

1. Распакуй ZIP на компьютере.
2. Создай новый репозиторий на GitHub (можно Private).
3. Загрузи в репозиторий **содержимое** папки `FRIDAY_OS_Mobile_Stage1`, включая скрытую папку `.github/workflows`.
   Удобнее всего: открой репозиторий → Add file → Upload files и перетащи все файлы и папки.
4. Открой вкладку **Actions**. Если GitHub попросит разрешить workflows, нажми разрешить.
5. Выбери **Build F.R.I.D.A.Y. OS APK** → **Run workflow** (если сборка не стартовала автоматически после загрузки).
6. Дождись зелёной галочки у завершённого запуска.
7. Открой запуск workflow, найди **Artifacts** и скачай `FRIDAY-OS-Mobile-debug-APK`.
8. Распакуй скачанный архив — внутри будет `app-debug.apk`. Перешли его на Android и установи. Если Android спросит, разреши установку из этого источника.

## Важно

- Это debug APK для тестирования, не подписанный релиз для Google Play.
- Приложение обращается к `https://friday-ai-backend-gfc4.onrender.com`.
- APK может запускаться, даже если сервер отвечает ошибкой модели; для ответов ИИ сначала должен работать endpoint `/chat`.
- Не добавляй секреты или HF_TOKEN в приложение или репозиторий.
